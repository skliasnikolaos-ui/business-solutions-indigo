# BUSINESS SOLUTIONS by INDIGO GROUP

Αυτόνομο website για τις υπηρεσίες **Business Advisory & Operations**, **Contracts** και **Business Solutions**, στο design της INDIGO GROUP. Δίγλωσσο (EL / EN).

## Σελίδες
- `/` Αρχική
- `/services` Υπηρεσίες
- `/services/advisory` · `/services/contracts` · `/services/solutions`
- `/approach` Προσέγγιση
- `/about` Ποιοι είμαστε
- `/contact` Επικοινωνία (η φόρμα ανοίγει email προς info@indigogroup.com.gr)

Τα κείμενα βρίσκονται στο `src/content.ts`.

## Τοπική εκτέλεση
```bash
npm install
npm run dev
```

## Build / Δημοσίευση
```bash
npm run build
```
Ο φάκελος `dist/` ανεβαίνει σε Vercel, Netlify ή οποιοδήποτε static hosting (περιλαμβάνονται `vercel.json` και `public/_redirects`).
